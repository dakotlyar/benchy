# Benchy 0.11.0

Benchy 0.11.0 is a Windows release about the two ends of a machine's life with Benchy: putting it on, and taking it off again. The installer has a new look and is no longer stopped by a running Benchy, the uninstaller is now a proper wizard instead of a PowerShell script, and the uninstall really does remove everything Benchy put on the computer, including the parts that live outside your own account. It brings desktop client 0.12.0 and native engine 0.9.0, which add the Settings window and the repair for a computer that is "paired twice". The server packages and the Linux command line are unchanged, so this release matters to you if you run Benchy on a Windows desktop or look after Windows test machines.

## What changed on Windows

### The installer

The installer and the uninstaller now share one look: a header, a strip showing where you are, and lists of what will land where. The first page says what the install will do, on your account and not for all users, and shows a shield only where Windows might ask for permission (for the Visual C++ Runtime, if it is missing). When you upgrade, the first page is a table of what you have now and what you will have after, with a line that says your results, settings and installed tests are kept and, if the computer is paired, which server and system name stay paired. The install itself shows a list of steps (checking files, the Visual C++ Runtime, copying, adding the Start menu and log on entries, starting both engines), with the log behind **Show details**. If an install fails, the last page says what state the computer is in and what to do, with the log path and **Copy details**.

The installer no longer refuses to run while Benchy is open. It stops Benchy, installs, and starts it again the way it was. If the Benchy window or its tray icon is open, the installer asks the client to quit. If a server job is running, the first page says so, and the job is stopped, with the tests that already finished uploaded first. A test you started in the Benchy window is stopped and its partial result is kept. The installer only stops and waits when it cannot proceed: for example a `benchy.bat` window left open, or a test running in a client older than 0.12 (the first upgrade from 0.10.1 is one of those). The page then names what to close and keeps **Next** off until it is closed.

A computer that runs administrator tests unattended has its own protected copy of the engine. On an upgrade the installer shows its version in the table and offers **Update the unattended agent too**, ticked, when that copy is older than the new engine. If you leave it ticked, the installer asks Windows once at the end. If you decline or it fails, the install still succeeds and the last page says how to update it later, in Settings.

### The uninstaller

`%LOCALAPPDATA%\Benchy\uninstall.exe` is a wizard. It is what **Apps & Features**, the Start menu and the new **Uninstall Benchy...** button in Settings run. It starts with **What goes**, a list of everything it found on this computer, with a tag on the parts that are for all users, and two choices:

- **Keep my results and settings**, ticked by default. It covers both engines' data: `%USERPROFILE%\.benchy`, `%LOCALAPPDATA%\benchy-engine`, and the client's own settings. The line shows the number and size of results.
- **Keep installed tests**, unticked by default. It is the downloaded and built test files, which download again if you ever need them.

If anything runs, the next page says what will be stopped. Then **Uninstall** asks Windows for permission once, when something is machine-wide, and removes everything in one go. If you decline, nothing has been changed, and the wizard says so and offers **Try again**. Files that are in use are queued and removed the next time Windows starts; the last page lists them with the reason and has **Copy the list** and **Restart now**. The last page also reminds you that the server keeps listing this computer until an administrator removes it on the Systems page, and names software that Benchy installed for administrator tests, such as PassMark PerformanceTest, which stays and can be removed from Windows' Installed apps.

The uninstaller carries its own checked copy of the engine, so a broken or half-deleted install can still be removed.

### uninstall.ps1 and install.bat installs

`uninstall.ps1`, which a `install.bat` install keeps, now does the same job. It calls the engine's `agent reset` for the all-users parts, splits the old "remove user data" switch into `-KeepResults`, `-KeepSettings` and `-KeepInstalledTests` (`-RemoveUserData` still means remove all three), and can list what it would remove with `-Inventory`. See the user guide's [Resetting and uninstalling](../../documentation/user-guide/reset-and-uninstall.md).

### The desktop client and the engine

Client 0.12.0 adds the alert band, the agent bar, the Settings window and the "runs as administrator" marker in the test list. Engine 0.9.0 adds `agent inventory`, `agent reset` and the paired-twice information in `agent status`. Their own notes have the details.

## Upgrading

Run the new installer over the old one. Settings, results and pairings carry over. Four things are different from 0.10.1.

1. **The installer stops and restarts Benchy.** You no longer have to quit it first. If a server job is running, it is stopped and the finished tests upload first, so pick a quiet moment on a machine that is working through a schedule.
2. **The uninstaller is now `uninstall.exe`.** It replaces the `uninstall.ps1` entry in Apps & Features. A fresh or upgrading GUI install registers it. A machine installed with `install.bat` keeps `uninstall.ps1`.
3. **A silent `uninstall.exe /S` returns at once.** Like every NSIS uninstaller it starts a copy of itself in `%TEMP%` and exits, so your script or management tool sees 0 straight away and cannot see a failure. To wait for the result, run it as `uninstall.exe /S _?=%LOCALAPPDATA%\Benchy`, which waits for the uninstall to finish and returns its exit code. That form leaves `uninstall.exe` itself in the install folder, so delete it afterward. The options are `/KEEPRESULTS=0|1` (default 1), `/KEEPTESTS=0|1` (default 0) and `/LOG=path`.
4. **The exit codes.** The installer's code 3 now means only that Benchy was running and could not be stopped. The uninstaller returns 0 (all removed), 1 (cancelled), 2 (no user profile or bad arguments), 3 (Benchy is running and could not be stopped), 5 (Windows did not give permission: nothing changed), 3010 (removed, with leftovers queued for the next restart), 40 (not everything removed and some not queued) and 50 (anything else).

A silent install (`/S`) still never updates the unattended agent. Do that from Settings, or with `agent setup-elevated --update`. A silent uninstall asks Windows once like the wizard; with no desktop to show the prompt it stops with exit code 5 and changes nothing.

A machine that ended up paired twice, with an old unattended setup and a fresh pairing, could not be repaired in 0.10.1: every undo command refused. In 0.11.0 the fix is in Settings (Server agent), or `benchy-engine agent reset --keep user` or `--keep unattended`.

## Known limits

- The pairing form is still in the Server dialog, which Settings opens. A pairing is not moved into the Settings window yet.
- The installer does not offer to wait for a running server job to finish. It stops it, after warning you on the first page.
- You cannot withdraw a single test you accepted for administrator runs. A reset removes all of them together.
- A result from a run started in the window that failed to upload is not retried by itself. It waits on the Results and uploads page, where **Upload now** sends it.
- Reset and uninstall do not remove products Benchy installed for administrator tests (for example PassMark PerformanceTest for all users), and "Forget this system" does not yet tell the server or the agent.
- A silent `uninstall.exe` returns at once unless called with `_?=` (see above).
- A file that is locked when you uninstall is queued for the next restart, and until then it and its folder are still there. If you uninstall and see the list of leftovers, restart Windows before you install Benchy again.
- The installer and its files are still unsigned, so Windows shows the publisher as Unknown, and Defender may flag `benchy-engine.exe`, as in 0.10.1.
- Windows only: none of the new installer, uninstaller or Settings pages exist on Linux.
