# Benchy 0.16.2

This release fixes unattended Windows machines that never ran a scheduled test needing administrator rights or a machine-wide install. It goes with engine 0.14.1 and client 0.17.1.

## Waiting for an acceptance is now visible

A test like that has to be accepted once, at the machine, before the server will send it. The server used to say a schedule was waiting for that only while the schedule was due, so between runs nobody could see it and nothing could be accepted ahead of time. Now the server tells the machine what is waiting on every check-in, so the desktop client can show it and offer to accept it straight away, with one administrator prompt for any number of tests.

The server's own pages say it too. A schedule's page has a line at the top such as "Held on 1 of 2 machines: needs acceptance at the machine (Title 1.2.0)". The systems list marks a machine that is waiting with "Needs acceptance", and the main page counts them. Nothing is stored for this; it is worked out when you open the page.

Older engines and clients are unaffected: they get the same information in the same shape and show it as they always did.
